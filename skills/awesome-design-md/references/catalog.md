# Awesome Design MD Catalog

This repository is a curated collection of `DESIGN.md` files extracted from public websites. The skill should use it as a source of brand-specific UI directions, not as a generic design taste guide.

## Fast Selection Rules

1. Prefer an exact brand match when available.
2. If the product type matches but the brand does not, choose the closest visual language in the same category.
3. If multiple entries fit, pick the one with the strongest distinctive system and simplest translation into UI.
4. When you infer a match, say so explicitly.

## Useful Heuristics

- Developer-facing product with dark theme and precision: Cursor, Vercel, Warp, Supabase, Resend
- Editorial or brand-forward marketing site: Claude, Notion, Sanity, Apple, Airbnb
- Data-dense dashboard or analytics product: ClickHouse, PostHog, Sentry, Airtable, Linear
- Friendly onboarding or collaboration-heavy SaaS: Intercom, Zapier, Miro, Figma, Cal.com
- Strong black-and-white or monochrome identity: Vercel, Apple, Nike, Ollama
- Neon, glow, or terminal-native feel: Warp, OpenCode AI, VoltAgent, Minimax

## What To Extract From A DESIGN.md

- Color tokens and accent strategy
- Typography hierarchy and weight
- Surface treatment and border radius
- Layout density and spacing rhythm
- Navigation structure and CTA behavior
- Imagery style, illustration style, or screenshot treatment
- Motion cues only when they are clearly part of the source language

## When To Ask The User

- The user wants a style but gives no target brand or product type.
- The requested brand is not in the catalog and there is more than one plausible match.
- The user wants to combine two different design languages and the tradeoff matters.

## Preferred Clarifying Question

Ask a short, direct question that gives the user concrete choices.

Example:

`Qual DESIGN.md você quer usar como base? Ex.: Apple, Notion ou Vercel.`
